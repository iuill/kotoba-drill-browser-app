**見本を聞く → 声に出す → 自分の声を聞き返す。**

日本語の発音を繰り返し練習するブラウザアプリです。難聴者を含む成人の自主練習を想定し、文字・色・動きでも進行を伝えます。

ログインは不要です。見本音声を収録しているため、音声合成エンジンをインストールせずに練習できます。音声認識を使わず、聞く・話す・聞き返すだけでも利用できます。

## どんな練習ができる？

| モード | 練習すること | 例 |
| --- | --- | --- |
| 1音 | 選んだ音をひとつずつ発声 | か・き・く |
| 2音 | 選んだ音と母音をつなげて発声 | かあ・あか |
| 単語 | 選んだ音を含む言葉を発声 | かさ・かぎ |

行ごとの選択にも、苦手な音だけの指定にも対応します。内蔵教材は979語。自分の単語を追加したり、よく使う設定を練習セットとして保存したりできます。

- **声と速さを選ぶ**：8種類の見本音声を切り替えて試聴できます。
- **繰り返して練習する**：一時停止、ひとつ戻る、同じお題の繰り返し、自動／手動録音に対応します。
- **発音のしくみを見る**：舌・唇・息の模式図や、破裂音・摩擦音などのガイドを表示。2つの音も並べて比較できます。
- **自分の声を確かめる**：録音の聞き返し、見本と録音のスペクトル比較、任意の音声認識を使えます。
- **練習を振り返る**：履歴と録音を保存し、バックアップを書き出せます。

## はじめの使い方

1. **スピーカー・マイクを確認**：見本を試聴し、自分の声を録音して聞き返します。マイク調整では、最初の3秒は静かに待ち、画面の案内が変わったら話してください。
2. **練習を選ぶ**：「1音・2音・単語」からモードと対象音を選びます。発音のコツを見てから進むか、「この音で練習する」ですぐに始められます。
3. **聞いて、声に出す**：見本と合図のあとに発声します。標準設定では、録音した声を自動で再生し、次のお題へ進みます。声・速さは練習画面から変更できます。
4. **気になる音を練習し直す**：「ひとつ戻る」「繰り返し」を使います。認識オンなら、直近の聞き取りからそのお題へ戻ることもできます。

音声の出力先はOS、録音マイクはアプリの設定で選びます。残したい録音は「保存」を押してください。

| キー | 操作 |
| --- | --- |
| Space | 開始・一時停止・再開 |
| R | 繰り返しの切り替え |
| ← / → | ひとつ戻る / 次へ |

入力中やポップアップ表示中は練習用ショートカットを抑止します。別タブへ移動すると一時停止します。

## 見本の声

初期設定は**四国めたん**です。VOICEVOX Nemoの女声1・男声1、四国めたん、春日部つむぎ、東北ずん子、東北きりたん、青山龍星、剣崎雌雄の8声を収録しています。

収録音声は合計約64.7MBですが、再生するお題だけを読み込みます。未収録の追加教材は、利用可能な日本語のブラウザ音声で読み上げ、その旨を画面に表示します。ブラウザ音声を直接選ぶこともできます。

## 音声認識について

**実験的な機能で、初期状態はオフです。**「設定・教材」から有効にできます。

| 方式 | 特徴 |
| --- | --- |
| ブラウザ標準（初期選択） | アプリ側のモデル取得・APIキーは不要。録音音声がブラウザの認識サービスへ送信される場合があります |
| 端末内モデル | 初回にモデルを取得し、認識は端末内で実行。GPU搭載のゲーミングPCを推奨します |

端末内モデルはWhisper Tiny／Base／Small、Kotoba-Whisper v2.2、Cohere Transcribeを選べます。容量・処理方式・未解決の制約は[音声認識の説明](docs/models.md)を参照してください。

1音練習は、認識オフなら1回、オンなら「か・か・か」のように3回発声します。短い単音では文字が返らないことがあるためで、見本も同じ回数流れます。3回でも認識の成功を保証するものではありません。

**認識結果は発音の採点ではありません。** 特に1音・無意味な2音では参考程度です。一致しても発音の正確さを保証せず、不一致でも減点しません。

## 利用環境とデータ

PCのEdge／Chromeを主な対象とします。マイクには **localhostまたはHTTPS** とブラウザの許可が必要です。インターネット接続を前提とし、オフライン対応はありません。ブラウザ標準認識はPC版Chrome／Edge 135以降が対象で、スマートフォン・Safariには対応していません。

スマートフォンでのアプリの音声動作は未検証です。収録形式のOgg Opusは[iOS／iPadOS 18.4以降](https://developer.apple.com/documentation/safari-release-notes/safari-18_4-release-notes)を基準としますが、マイク・連続再生を含むアプリ全体の対応を保証するものではありません。

- 設定・教材・履歴・保存録音はブラウザ内に保存します。端末間の自動同期はなく、サイトデータの削除で失われる場合があります。
- アプリ独自のデータ収集や自動診断送信はありません。ブラウザ標準認識では録音音声、オンラインのブラウザ読み上げではお題のテキストが各サービスへ送られる場合があります。
- 端末内モデルはHugging Faceから取得します。キャッシュは再取得を減らすためのもので、ブラウザによって削除される場合があります。

<details>
<summary>録音の保存上限とバックアップ</summary>

一時録音は直近20件・合計50MBまでで、次の練習開始やページの再読み込みで破棄します。明示的に保存した録音は合計500MBまでです。大切なデータは履歴からバックアップを書き出してください。

バックアップはJSONです。復元は現在のデータを丸ごと置き換えます。録音を含まないバックアップでも、復元先の保存録音は削除されます。設定の初期化では、保存済みの教材・履歴・録音は残ります。

</details>

スペクトルは再生中に観測した周波数ごとのピークです。声質・音量・機器でも形が変わり、実際の音圧や発音の正誤を表しません。ブラウザ読み上げは解析対象外です。発音図解も一般的な模式図で、専門家による監修・練習効果の検証は行っていません。

## 手元で動かす・開発する

React＋TypeScript＋Vite、Bunを使用しています。標準環境はLinuxのDev Containerです。WindowsではWSL2を利用します。

```bash
git clone https://github.com/iuill/kotoba-drill-browser-app.git
cd kotoba-drill-browser-app
```

[開発ガイド](docs/development.md#開発環境)に沿ってコンテナを起動し、コンテナ内で実行します。既定のDev ContainerはホストのCodex standaloneを使います。補助CLIを使わないCompose起動手順も開発ガイドにあります。

```bash
bun install --frozen-lockfile
bun run dev
```

ホストのブラウザから `http://localhost:25173` を開きます。アプリの起動・ビルドに見本音声の再生成は不要です。
