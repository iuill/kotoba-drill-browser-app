# 現行設計

[使い方](../README.md)を支える実装の責務と、変更時に守る条件をまとめます。

## 構成

専用バックエンドを持たない日本語の静的アプリです。React・TypeScript・Viteで構成し、GitHub Pagesなどから配信できます。CIはプライベートでも実行し、Pagesへの配信は公開リポジトリのmainへのpushに限定します。認識は任意で、見本・録音・聞き返しだけでも練習できます。

| 層 | 主な実装 | 責務 |
| --- | --- | --- |
| 画面 | [App.tsx](../src/App.tsx)、[ui/](../src/ui/) | 設定の下書き、ダイアログ、進行・結果の表示 |
| 練習 | [engine.ts](../src/core/engine.ts)、[core/](../src/core/) | お題、出題順、セッション、状態遷移、区切り |
| 音声 | [browserAudio.ts](../src/audio/browserAudio.ts)、[audio/](../src/audio/) | 見本・合図・録音・発声検知・スペクトル |
| 認識 | [models/](../src/models/) | ブラウザ認識、Worker、モデル別アダプター、キュー・キャッシュ |
| 保存 | [store.ts](../src/storage/store.ts) | IndexedDB、録音上限、削除・バックアップ・復元 |
| 教材・図解 | [materials.ts](../src/core/materials.ts)、[content/](../src/content/) | 読みと音の単位、教材、発音の説明 |

録音Blob・モデル・周波数配列をReactの状態へ抱え込まない。モデル固有の前処理・推論・後処理はアダプターへ閉じ込め、重い認識処理はWorkerで行う。音声のデコード・リサンプリングはメインスレッドで行う。

## お題と設定

- 1音、対象音と母音をつなぐ2音、対象音を含む単語を扱う。拗音は一単位で扱い、文字単位に分割しない。
- 2音は母音と前後の順序、単語は語頭・語中・語尾を指定できる。音選びと練習には同じ候補生成を使う。候補0件では開始できない。
- ランダムでは一巡まで重複させず、複数候補があれば一巡の境目でも同じお題を続けない。繰り返しオンでは現在のお題に留まる。
- 音声認識オフの1音は1回発声。オンでは `Prompt.repetitions: 3` とし、見本・発声・読み比較を3回分に揃える。録音・履歴・練習回数は1件・1回。回数未指定の履歴は1回として扱う。2音・単語・準備用試聴は1回。
- 3回発声の録音を複製したり、認識結果をお題で補完したりしない。発声の合間で録音が切れないよう、認識オンの1音だけ無音待ちを最低1100msとする。
- 初期設定は、か行の1音・ランダム・四国めたん0.85倍・毎回見本と聞き返し・自動録音・見本後の待ち時間なし・認識オフ。認識方式の初期選択はブラウザ標準。全項目は [defaults](../src/core/types.ts) を正とする。
- 音選びは行／個別音・条件・図解を共通ウィザードで扱い、図解を省略しても同じ検証・保存処理を通す。キャンセルで未適用の変更を保存しない。
- 声・速度だけの変更はお題と出題順を保持する。出題条件の変更ではデッキを更新する。認識オフへの復旧も通常の設定適用を通し、現在・以後の1音を1回に戻す。
- 設定初期化は設定パネルを開いたまま初期値を適用し、下書きを更新する。保存済み教材・練習セット・履歴・録音・モデルキャッシュは削除しない。

## 練習の進行

基本の順序は、認識の準備（有効時のみ）→見本→待ち時間・受付合図→発声待ち・録音→聞き返し→次のお題。録音完了後の認識は聞き返しと並行する。

- 一時停止・戻る・設定変更・別タブへの移動で音声とタイマーを止め、途中録音を破棄する。完了済み履歴は保持し、途中録音は回数へ含めない。
- 非同期処理はセッション・処理の世代と履歴IDで対応付ける。古い処理の完了を現在のお題へ適用しない。
- 再開時は見本の「毎回／お題が変わったとき／手動／オフ」に従う。中断した見本は必要なら先頭から再生する。
- 未開始・終了後のSpaceは新しいセッションを開始する。設定適用や履歴の聞き返しで終了済みセッションを復活させない。
- 時間・回数の区切りは、現在の録音と聞き返しが終わってから通知する。練習時間には見本・発声待ち・録音・聞き返しを含め、一時停止とモデル準備を除く。
- 「このお題に戻る」は履歴IDから出題順を巻き戻し、一時停止・繰り返しオンにする。次へで元の順序を進む。別セッション・出題条件から外れたお題・終了後・区切り中には戻らない。
- 認識の準備失敗時は再試行または認識なしで復帰できる。開始後の認識エラーで基本練習全体を止めない。

## 音声経路

- 見本は生成済み音声またはブラウザ読み上げ。未収録の読みだけブラウザ音声へ切り替え、理由を表示する。収録ファイルの取得失敗を別の音声への切り替えで隠さない。
- 収録見本の速度はピッチを保って変更する。1音の3回再生は同じファイルを300ms間隔で繰り返す。2音・単語は丸ごと生成した音源を使う。
- 見本の前に録音用マイクを準備し、音声経路の切り替えによる聞こえ方の変化を抑える。録音マイクは選択でき、出力先はOSで管理する。
- 練習の最初と2回目以降の見本直前に別の合図を鳴らす。モデル・見本の取得が終わってから合図→見本の順に再生する。準備用試聴には合図を付けない。
- 録音受付の合図は見本と待ち時間のあと。合図が終わるまで録音を開始せず、中断時は後続処理も止める。
- 発声検知はRMSと無音時間を使う。録音経路に150msの遅延を設け、正常終了時は180ms待って末尾を保存する。中断時は即時停止する。マイク入力をスピーカーへ接続しない。
- MediaRecorderはWebM/Opusを優先し、非対応時はOgg/MP4等を使う。実際のMIMEを保存する。録音上限到達時は理由を表示して一時停止する。
- 音声の停止でトラック・解析ノード・タイマーを解放する。共有AudioContextと、その再生専用に作ったContextを区別して閉じる。

生成条件と再生成手順は[開発ガイド](development.md)、権利表記は[音声の説明](../public/audio/samples/README.md)を参照。

## スペクトルと認識表示

- スペクトルは既存音声経路をAnalyserNode（FFT 4096）へ分岐し、50Hz〜8kHzを48帯域・対数軸で小型Canvasへ表示する。縦軸は−90〜0dBの相対レベルで、音源ごとの自動正規化はしない。
- 見本は青の実線、録音は緑の破線。再生中に観測した各帯域の最大値を2本だけ保持する。全音声の平均や同じ時刻の波形ではなく、途中停止時は再生した範囲だけのピーク。
- 観測は50ms周期、描画は最大20fps（動きを減らす設定では4fps）。お題・セッション・声・速度・音量・マイク等の変更で比較を消し、新しい録音で録音側を更新する。
- 録音Blobの弱参照で対応するお題を確認し、別のお題・保存履歴・準備用試聴を現在の見本と混ぜない。マイク入力は現在の棒表示のみ。ブラウザ読み上げと解析不能時は、取得できないことを表示する。
- 認識結果は読みを比較する。未知の漢字・複数読みは「読みは要確認」とし、認識の不一致を発音の誤りと断定しない。
- 「直近の聞き取り」は録音順で最新の処理済み結果を、お題・録音時刻とともに表示する。次の認識待ちで消さず、遅い古い結果で上書きしない。同じ文字でも新しい履歴IDなら更新を伝える。
- 結果や案内の長さで主要操作ボタンの位置を動かさない。背景の演出は文字・ボタンを動かさず、演出オフ・動きを減らす設定にも対応する。

認識方式の入力・処理・制限は[音声認識](models.md)、図解の範囲と出典は[作図方針](articulation.md)を参照。

## ダイアログと操作

- 設定・モデル管理・履歴・図解は共通Modalを使う。最前面だけを操作でき、背景の操作とスクロールを抑止する。
- 閉じる・Escape・パネル外クリックは同じ終了処理を通す。内側から外側へドラッグした場合は閉じない。保存・削除・復元中は外側クリックでも閉じない。
- 開いた時点で練習を一時停止する。閉じた後は入口へフォーカスを戻し、自動再開しない。ネストした図解・確認画面は一段ずつ閉じ、元の下書きを保つ。
- 入力中・ダイアログ表示中は練習ショートカットを抑止する。
- スピーカー・マイク確認では、試聴と録音を別のダイアログで行う。マイク調整は最初の3秒の静音測定をカウントダウンで知らせ、発声待ち・録音・再生を文字と色で区別する。
- 発音のコツではお題内の音と練習対象の他の音を選べる。図解の切り替えは練習条件・お題・履歴を変更しない。

## 保存・容量・復元

IndexedDB v1に設定・練習セット・教材・履歴・保存録音を保持する。認識モデルはCache Storage、一時録音はメモリに保持する。

| データ・処理 | 上限・保持方針 |
| --- | --- |
| 一時録音 | 直近20件かつ50MiB。古いものから破棄し、次の練習開始・再読み込みでも破棄 |
| 保存録音 | 500MiB。自動削除せず、上限時は新たな保存を止める |
| 履歴 | 自動削除しない。録音のみ削除した場合もお題・認識結果は残す |
| 録音 | 初期上限10秒、設定範囲1〜30秒。30秒発声がなければ一時停止 |
| 認識キュー | 実行中1件＋待機最新1件。置換した待機分はスキップとして記録 |
| 端末内認識 | 取得量が5分増えなければ準備を中断。推論上限5分 |
| ブラウザ認識 | 音声入力開始待ち10秒、全体上限90秒 |

- 履歴の削除では紐付く保存録音・一時録音も削除する。削除・復元はトランザクションで処理する。
- バックアップは形式・バージョン付きJSON。録音は任意でBase64を含め、モデルキャッシュは含めない。
- 復元は内容を検証したあと、確認を経て丸ごと置換する。録音なしのバックアップも現在の録音を削除する。置換前の書き出しを案内する。
- 復元前に認識処理を中止し、遅い結果を復元後の同一IDへ書き込まない。起動・復元時に残った認識待ちは中断扱いへ整理する。
- 破損・未対応形式の復元で現在のデータを壊さない。保存形式を変える際は、互換性と復元失敗時の保全を検討する。

## 通信と対応範囲

録音をアプリの配信サーバーへ送らない。ブラウザ標準認識では録音、オンラインのブラウザ読み上げではお題が各サービスへ送られる場合がある。選択画面に表示し、認識方式を無断で切り替えない。診断情報には録音・練習内容を含めず、自動送信しない。

アカウント・端末間同期・オフライン動作・文章練習は対象外。PC版Edge／Chromeを主対象とし、スマートフォンの音声動作、モデルごとの短音精度、図解の専門的監修は確認範囲を分ける。[テスト方針](testing.md)を参照。
