# 発音のコツ：作図と参考資料

練習画面の「発音のコツ」から、口の断面・正面の唇・短い説明を表示する。
「発音のしくみガイド」では音の作り方・場所・声と拍を学び、図のある任意の2音を比較できる。
図は本プロジェクトで独自に描いたSVG。外部サイトの図・写真・音声・文章の転載やトレースはしていない。
図を見るための外部通信は行わない。

## 図の範囲

- 教材選択にある清音・濁音・半濁音・拗音を対象とする。2音・単語ではモーラ単位で選択できる。
- 母音の舌の前後・高さ、子音の主な閉鎖／狭めの位置、唇の閉鎖、口／鼻への息の出口を模式的に示す。
- 「出だし」「母音へ」を手動で切り替える。実時間の発音運動、実測した解剖形状、気流シミュレーションではない。自動ループや光の点滅は使わない。
- 拗音は一拍として扱う。断面図は主な調音位置の目安に限定し、舌全体の口蓋化や連続運動の精密な再現は行わない。
- 分類一覧は教材で選べる全音を行別に示し、拗音は展開して確認する。ザ行は摩擦音・破擦音の両方に含め、分類を選んだときの図も閉鎖の有無に合わせる。通常の「発音のコツ」と自由比較は代表形を使い、別の始め方がある旨を添える。ガ行の鼻濁音・摩擦化など、すべての異音を図示するものではない。
- 「ん」「っ」「ー」は文脈により変わるため説明のみ。未対応の外来音等は、既知の音へ勝手に置き換えず図がない旨を表示する。
- 認識の一致・不一致と図の選択は連動させない。個人の舌位置や発音の誤りを判定する機能ではない。
- 専門家による図・説明の監修、臨床的な有効性の検証は未実施。
- 基礎ガイドは破裂・摩擦・破擦・鼻音・弾き音・接近音／半母音と母音を対象とする。破擦音のみ、閉鎖と母音の間に摩擦の模式図を加える。接近音・母音は完全閉鎖や強い摩擦を作らないこと、鼻音は口の閉鎖と鼻への出口を分けて説明する。
- 2音比較は出だしの代表的な分類を使う。「て／け」は方法・母音が同じで主な閉鎖位置が異なる比較例。「た／さ」は方法、「か／が」は声帯の振動、「あ／い」は母音の比較例。ほかの組み合わせも選択できる。分類が同じでも、二次的な舌の形・個人差・異音まで同一とは扱わない。
- 声門の内部、舌全体の精密な口蓋化、気流・声帯の振動の実時間アニメーションは描かない。声門は説明で案内し、拍は文字のブロックで可視化する。

## 参考資料

| 分類 | 一覧の範囲・注意 |
| --- | --- |
| 破裂音 | カ・ガ・パ・バ行、た・て・と、だ・で・ど、および対応する拗音。ガ行は閉鎖して離す代表形 |
| 摩擦音 | サ・ハ行と拗音。ザ行・じゃ行は閉じずに始める場合。ハ行は場所が分かれる |
| 破擦音 | ち・つ・ちゃ行。ザ行・じゃ行は閉じてから摩擦を作る場合 |
| 鼻音 | マ・ナ行と拗音。「ん」とガ行鼻濁音は文脈・異音として補足 |
| 弾き音 | ラ行と拗音の代表形 |
| 接近音・半母音 | や・ゆ・よ・わ。拗音全体をこの分類へまとめない |
| 母音 | あ・い・う・え・お。通常の有声の形を図示し、無声化の有無を判定しない |
